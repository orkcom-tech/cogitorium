{{/* The panel around a shell — which is all of a terminal a template can render. The session itself is a live PTY over a socket, redrawn as bytes arrive. A template renders a thing that exists at a moment, and a terminal is the opposite of that. What IS renderable is everything around it: whether there is one, and what kind of machine is on the other end. That is the half somebody reads before they type, and it is the half worth being able to override. There is no start button any more. A terminal that has to be started is a terminal you notice; this one opens with the panel and keeps its shell when you walk away, so what a plugin overrides here is a description rather than a control. */}} {{define "cog.drawer.terminal"}}
{{if .Available}} {{if .Host}}

A shell on this machine, as the account this server runs as — the same reach you have sitting at it — opened in this workspace's own directory, where what you write stays. Closing this panel leaves the session running; opening it again comes back to it.

{{else}}

A shell in the sandbox gears run in: no network, and nothing of this server's mounted. It has a COPY of this workspace's files and nothing is carried back out, so a file written here is gone when the session ends. Closing this panel leaves the session running.
